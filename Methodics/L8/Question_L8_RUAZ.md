## 🔹 БЛОК 1: РЕФЛЕКСИВНЫЕ ВОПРОСЫ / REFLEKSİV SUALLAR
*(Личное отношение / Şəxsi münasibət)*

### Вопрос 1 / Sual 1
**RU:** Если бы вы завтра стали руководителем отдела, внедряющего ИИ-систему для оценки сотрудников, какие три этических принципа вы бы заложили в основу и почему?  
**AZ:** Əgər sabah işçilərin səmərəliliyini qiymətləndirən SI-sistemini tətbiq edən departamentə rəhbər təyin olunsaydınız, hansı üç etik prinsipi əsas götürərdiniz və niyə?

🎯 **Цель / Məqsəd:** Активизация личного отношения к теме / Mövzuya şəxsi münasibətin aktivləşdirilməsi

💡 **Ключевые точки / Əsas məqamlar:**
- **Справедливость / Ədalətlilik:** Система не должна дискриминировать / Sistem irq, cins, yaş üzrə ayrı-seçkilik etməməlidir
- **Прозрачность / Şəffaflıq:** Сотрудники должны понимать критерии оценки / İşçilər qiymətləndirmə meyarlarını anlamalıdır
- **Подотчётность / Məsuliyyət:** Кто отвечает за ошибку алгоритма? / Alqoritmin səhvinə görə kim cavabdehdir?

🗣️ **Наводящие вопросы / Yönəldici suallar:**
- RU: «Если система показывает "неэффективность", но вы видите обратное — кому доверитесь?»  
- AZ: «Sistem "səmərəsizlik" göstərsə, amma siz əksini görsəniz — kimə etibar edərdiniz?»

**AZ:** Ədalətsiz qərarın sizin lehinize olmadığı bir vəziyyəti xatırlayın. Bu qərarı insan deyil, alqoritm qəbul etsəydi, özünüzü necə hiss edərdiniz?

🎯 **Цель / Məqsəd:** Эмпатия и понимание человеческого измерения ИИ / Empatiya və İİ-nin insan ölçüsünü dərk etmək

💡 **Ключевые точки / Əsas məqamlar:**
- Алгоритм не может «выслушать» / Alqoritm «dinləyə» bilməz
- Право на объяснение / İzahat almaq hüququ
- Восприятие справедливости / Ədalətliliyin qavranılması

### Вопрос 3 / Sual 3

**AZ:** İnsan resurslarının idarə edilməsində «İİ-nin köməyi» ilə «İİ-nin nəzarəti» arasında sərhədi harada çəkirsiz?

🎯 **Цель / Məqsəd:** Исследование грани между оптимизацией и слежкой / Optimallaşdırma ilə nəzarət arasındakı sərhədin araşdırılması

💡 **Ключевые точки / Əsas məqamlar:**

- **Контроль / Nəzarət:** Отслеживание каждого действия, времени простоя / Hər hərəkətin, boş vaxtın izlənməsi
- **Критерий / Meyar:** Кто получает выгоду? / Kim fayda götürür?

## 🔹 БЛОК 2: КЕЙС-ВОПРОСЫ / KEYS SUALLARI
*(Анализ ситуаций / Vəziyyətlərin təhlili)*

### Вопрос 4 / Sual 4
**RU:** Кейс: Компания внедрила ИИ для скрининга резюме. Выяснилось, что система реже пропускает кандидатов старше 45 лет, хотя в правилах такого ограничения нет. Что произошло и как исправить?  
**AZ:** Keys: Şirkət CV-lərin süzgəcdən keçirilməsi üçün İİ tətbiq edib. Məlum olub ki, sistem 45 yaşdan yuxarı namizədləri daha az keçirir, halbuki qaydalarda belə məhdudiyyət yoxdur. Nə baş verib və necə düzəltmək olar?

🎯 **Цель / Məqsəd:** Понимание механизма скрытой предвзятости (bias) / Gizli qərəzin (bias) mexanizmini dərk etmək

💡 **Ключевые точки / Əsas məqamlar:**
- **Что произошло / Nə baş verdi:** Модель обучалась на исторических данных с перекосом / Model tarixi məlumatlarda qeyri-bərabərlik əsasında öyrənib
- **Как выявить / Necə aşkar etmək:** Аудит по демографическим группам / Demoqrafik qruplar üzrə audit
- **Как исправить / Necə düzəltmək:** Перебалансировка данных, human-in-the-loop, мониторинг справедливости / Məlumatların balanslaşdırılması, insan nəzarəti, ədalətlilik monitorinqi

🗣️ **Наводящие вопросы / Yönəldici suallar:**
- RU: «Можно ли полностью "очистить" данные от предвзятости, если она отражает реальную историю?»  
- AZ: «Məlumatları qərəzdən tam "təmizləmək" olarmı, əgər bu qərəz şirkətin real tarixini əks etdirirsə?»

**AZ:** Keys: Bank kreditlərin təsdiqi üçün İİ istifadə edir. Müştəriyə imtina edilib, amma sistem səbəbi izah edə bilmir — «kommersiya sirri». Müştəri şikayət verir. Siz necə davranarsınız?

💡 **Ключевые точки / Əsas məqamlar:**
- **GDPR и право на объяснение / GDPR və izahat almaq hüququ:** Автоматизированные решения требуют человеческого участия / Avtomatlaşdırılmış qərarlar insan iştirakı tələb edir
- **Возможные действия / Mümkün addımlar:** Общие критерии + право на апелляцию / Ümumi meyarlar + apellyasiya hüququ
- **Коммуникация / Kommunikasiya:** Честно объяснить ограничения системы / Sistemin məhdudiyyətlərini dürüst izah etmək

### Вопрос 6 / Sual 6
**RU:** Кейс: ИИ прогнозирует, что сотрудник уволится в ближайшие 3 месяца. Менеджер получает предупреждение. Что он должен (и не должен) делать с этой информацией?  
**AZ:** Keys: İİ işçinin yaxın 3 ayda işdən çıxacağını proqnozlaşdırır. Menecer xəbərdarlıq alır. O, bu məlumatla nə etməlidir (və nə etməməlidir)?

💡 **Ключевые точки / Əsas məqamlar:**
- **НЕ делать / ETMƏMƏLİ:** Не ограничивать возможности, не менять отношение на основе вероятности / İmkanları məhdudlaşdırmamaq, ehtimala əsasən münasibəti dəyişməmək
- **Делать / ETMƏLİ:** Использовать сигнал для диалога, предложить поддержку, проверить точность модели / Siqnalı dialoq üçün istifadə etmək, dəstək təklif etmək, modelin dəqiqliyini yoxlamaq

## 🔹 БЛОК 3: ДЕБАТНЫЕ ВОПРОСЫ / DEBAT SUALLARI
*(Аргументация позиций / Mövqelərin arqumentasiyası)*

### Вопрос 7 / Sual 7
**RU:** Тезис: «Алгоритмы объективнее людей, поэтому этические риски ИИ преувеличены». Согласны или нет? Аргументируйте.  
**AZ:** Tezis: «Alqoritmlər insanlardan daha obyektivdir, ona görə də İİ-nin etik riskləri şişirdilir». Razısınız yoxsa yox? Arqumentləşdirin.

🎯 **Цель / Məqsəd:** Критический анализ природы «объективности» алгоритмов / Alqoritmlərin «obyektivlik» təbiətinin tənqidi təhlili

💡 **Аргументы ЗА / ARQUMENTLƏR LEHİNƏ:**
- RU: Не устают, нет эмоций, решения воспроизводимы  
- AZ: Yorulmurlar, emosiya yoxdur, qərarlar təkrarolunandır

💡 **Аргументы ПРОТИВ / ARQUMENTLƏR ƏLEYHİNƏ:**
- RU: Алгоритмы учатся на человеческих данных → воспроизводят предвзятость  
- AZ: Alqoritmlər insan məlumatları əsasında öyrənir → qərəzi təkrarlayır

🗣️ **Фасилитация / Fasilitasiya:**
- Разделите группу на две команды / Qrupu iki komandaya bölün
- После дебатов: «Какие условия сделали бы алгоритм действительно справедливым?» / Debatdan sonra: «Alqoritmi həqiqətən ədalətli edəcək şərtlər hansılardır?»

### Вопрос 8 / Sual 8

🎯 **Цель / Məqsəd:** Баланс между инновациями, эффективностью и приватностью / İnnovasiya, effektivlik və məxfilik arasında balans

💡 **Аргументы ЗА / ARQUMENTLƏR LEHİNƏ:**

💡 **Аргументы ПРОТИВ / ARQUMENTLƏR ƏLEYHİNƏ:**
- RU: Анонимизированные данные не нарушают приватность; согласие может быть получено «под давлением»

## 📋 ИНСТРУКЦИЯ ДЛЯ ФАСИЛИТАТОРА / FASILITATOR ÜÇÜN TƏLİMAT

### Подготовка / Hazırlıq
- [ ] Распечатать вопросы / Sualları çap etmək
- [ ] Подготовить флипчарт/доску / Flipçart/lövhə hazırlamaq
- [ ] Определить тайминг: ~3–4 минуты на вопрос / Tayminq: hər suala ~3–4 dəqiqə

### Проведение / Keçirilməsi
1. **Вступление / Giriş (2 мин / dəq):** Напомнить ключевые темы / Əsas mövzuları xatırlatmaq
2. **Выбор вопросов / Sualların seçimi:** Не обязательно проходить все 15 / Hamısını keçmək mütləq deyil, 5–7 kifayətdir
3. **Формат ответов / Cavab formatı:** 
   - Индивидуальные размышления / Şəxsi düşüncə (1 мин / dəq)
   - Пары/мини-группы / Cütlər/mini-qruplar (3–5 мин / dəq)
   - Общий круг / Ümumi dairə
4. **Роль фасилитатора / Fasilitatorun rolu:** 
   - Не давать готовые ответы / Hazır cavablar verməmək
   - Следить за вовлечённостью / İştirakı izləmək
   - Фиксировать ключевые идеи / Əsas fikirləri qeyd etmək

### Завершение / Yekun (5 мин / dəq)
